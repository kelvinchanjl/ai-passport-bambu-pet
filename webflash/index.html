给工牌刷上线线

固件 v4.7.1 · 线线六种状态 · 耗材颜色跟随 · 顶部时间和电量 · FoloToy AI Passport(ESP32-C3)

第一次刷 / 想全部重来

完整镜像从 0x0 写入。会清空工牌里的 Wi-Fi 和拓竹登录,刷完要重新扫码配网。

这个浏览器不支持网页刷机。请用电脑上的 Chrome 或 Edge 打开本页。 页面必须通过 https 或 localhost 打开,直接双击 html 文件不行。

已经在用线线,只升级

只写应用分区(0x10000),保留 Wi-Fi 和拓竹登录,刷完自动连上。工牌上必须已经是线线固件。

这个浏览器不支持网页刷机。 页面必须通过 https 或 localhost 打开。
  1. 用电脑版 Chrome / Edge 打开(手机、Safari、Firefox 不行)。
  2. 用能传数据的 USB 线连工牌(只能充电的线识别不到串口)。
  3. 点按钮,在弹窗里选工牌的串口(名字多半带 USB JTAG / usbmodem),然后点「安装」。
  4. 大约 1–2 分钟,进度走完后工牌自动重启。

选不到串口:换根线或换个 USB 口;还不行就按住工牌按键再插线进入下载模式。本页与拓竹(Bambu Lab)官方无关。
