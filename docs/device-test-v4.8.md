# v4.8 真机测试清单

v4.8 的代码只通过了主机测试和编译,下面这些项**全部未测**。用测试版固件(`sdkconfig.test`,`CONFIG_PET_LOG_REPORT_KEYS`)跑,串口日志里会打印堆信息(`heap@... free=... min=...`)。每项测完把结果和日期补在「结果」列。

| # | 项 | 通过标准 | 结果 |
|---|---|---|---|
| 1 | **min_heap:配网热点和配网页开着时** | 进「重新配网」,手机连热点并打开配网页,依次做:列表、添加(试连)、删除、完成;全程 `esp_get_minimum_free_heap_size()` ≥ **40 KB** | 未测 |
| 2 | min_heap:正常运行(云端 MQTT,不开热点),保存 5 个 Wi-Fi | 开机、断线重连、漫游扫描各一轮后,最低剩余内存 ≥ 40 KB(v4.7.1 实测约 47–49 KB) | 未测 |
| 3 | 多 Wi-Fi 选网 | 保存 ≥ 2 个,开机连信号最强的;关掉它后自动换下一个;全部连不上时按 1→60 秒退避重扫,不进配网 | 未测 |
| 4 | 添加 Wi-Fi 试连 | 正确密码 → 保存并留在新网络;错误密码 → 提示「密码不对」且列表不变;不在范围内的网络 → 提示「连不上」;试连时手机掉线后能重连热点 | 未测 |
| 5 | 原因码分类 | 输错密码时 STA 断开原因码是 15 或 204(日志 `wifi_add: connect failed, reason=`) | 未测 |
| 6 | 删除 | 删非当前、删当前连着的(自动换网);只剩 1 个时按钮置灰 | 未测 |
| 7 | 升级迁移 | 从 v4.7.x「只更新应用」(0x10000)升上来:配网保留,原 Wi-Fi 成为第 1 个,配网页显示一次「已自动加入」横幅,增/删/完成后消失 | 未测 |
| 8 | 降级兼容 | 降回 v4.7.x 仍能连第 1 个 Wi-Fi | 未测 |
| 9 | 恢复出厂 / 重新配网 | 行为和 v4.7.2 一致;恢复出厂后 NVS 里没有 `wifis`、`wmig` | 未测 |
| 10 | 手机上配网页的真实显示 | iOS 弹窗浏览器、安卓浏览器各看一遍:入口页、列表、添加、等待页、底部弹层和 toast 不被工具栏遮挡 | 未测 |

## 休眠(熄屏)

下面这些项**全部未测**(休眠功能只通过了主机测试和编译)。日志关键字:`sleep enter face=`、`sleep wake (`、`sleep screen lvgl mem used=`,都带 `heap free=… min=…`。

| # | 项 | 通过标准 | 结果 |
|---|---|---|---|
| S1 | 默认 2 分钟、A 全黑 | 首次升级后设置页显示「休眠：2 分钟」「熄屏画面：全黑」;不操作 2 分钟背光立即灭(无渐变),屏幕不再刷新 | 未测 |
| S2 | 第一下只亮屏 | 熄屏时分别单击/长按/双击 上、中、下:只亮屏,不翻页、不开设置、不换打印机;亮屏后再按才生效 | 未测 |
| S3 | 回到原页面 | 在详情页、耗材页、首页各熄屏一次,亮屏后还是那一页;亮屏时看不到旧画面一闪 | 未测 |
| S4 | 设置页开着到点 | 设置页开着不动 2 分钟:先关设置页再熄屏,亮屏是打开设置之前那一页 | 未测 |
| S5 | 自动亮屏 | 熄屏时打印机变成 暂停 / 断料 / 完成 / 失败 各一次:自动亮屏,暂停时切到那台;开机和 MQTT 重连后的第一个状态不亮屏 | 未测 |
| S6 | 不熄屏的场景 | 配网二维码 / 配网页、重新登录、恢复出厂确认页、演示模式、设置「关」:超过 5 分钟都不熄屏 | 未测 |
| S7 | 设置切换 | 休眠 关→2→5→关、熄屏画面 全黑→时钟→线线→全黑 单击即变,断电重启后保持 | 未测 |
| S8 | B 时钟 | 暗屏(约 8% 背光)显示时间、电量;有打印时显示机器名、进度条和百分比,没打印时只有时间和电量;状态条隐藏;时间每分钟跟着变 | 未测 |
| S9 | C 线线 | 暗屏显示睡觉的线线(毛色是当前耗材色)、时间、电量;线线不动、不眨眼;状态条隐藏 | 未测 |
| S10 | 防残影位移 | B/C 熄屏 15 分钟以上,整体每 5 分钟挪约 3 px,不出界 | 未测 |
| S11 | 低背光闪烁 / 啸叫 | B/C 的 8% 背光(LEDC 5 kHz 不变):肉眼和手机慢动作看不到闪烁,耳朵贴近听不到啸叫 | 未测 |
| S12 | 唤醒延迟 | A:按键到亮屏 ≤ 0.5 s(估算约 0.25–0.4 s,含 SLPOUT 等待);B/C 更快 | 未测 |
| S13 | min_heap | 熄屏/亮屏 A、B、C 各循环 20 次 + 熄屏挂 1 小时:最低剩余内存 ≥ 40 KB,无重启;MQTT 不掉线 | 未测 |
| S14 | 续航 | 同样条件下 A / B / C / 不熄屏 各跑一段,记录电量下降;电流只做过估算 | 未测 |
