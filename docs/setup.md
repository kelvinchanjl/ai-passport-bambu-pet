# 首次配网与拓竹账号登录

只需要做一次。之后断网、断电、重启,工牌都会自己重连。

![配网流程](images/setup_flow.png)

## 步骤

1. **开机看二维码**:没配过网的工牌开机后进入配网页,屏幕上有一个二维码,下面写着热点名 `Passport-XXXX`(XXXX 是这块工牌 MAC 地址的后 4 位,每块不一样)。
2. **手机连热点**:用手机相机扫二维码,手机会加入这个热点(开放热点,不需要密码)。扫不了就去手机的 Wi-Fi 设置里手动连 `Passport-XXXX`。
3. **打开配网网页**:手机一般会自动弹出配网页面。没弹出来就用浏览器打开 `http://192.168.4.1`。
4. **① 连接 Wi-Fi**:选家里的 **2.4 GHz** Wi-Fi,填密码。
5. **② 登录拓竹账号**:填拓竹账号的手机号或邮箱,点「获取验证码」,把收到的验证码填进去。
   这一步工牌会先连上你家的 Wi-Fi,再去访问拓竹服务器。
6. **③ 选择打印机**:网页会列出账号下的全部打印机(绿点表示在线)。最多勾 4 台,第一台是开机默认显示的那台。点「完成绑定」。
7. 工牌显示「绑定成功」,几秒后自动重启,然后就会一直自动连接。

小提示:工牌连上家里 Wi-Fi 时,热点的信道可能跟着变,手机可能会断开一下。网页提示出错的话,重新连上热点、刷新页面再试一次。

## 工牌里存了什么、连了哪里

- **拓竹密码从来不经过工牌**:登录用的是验证码,网页里没有密码框。
- 工牌在自己的 NVS 分区(命名空间 `petcfg`)里保存:
  - Wi-Fi 的名称和密码(连网必须用;最多 5 个,见下面[多个 Wi-Fi](#多个-wi-fi));
  - 拓竹账号的用户 ID、access token、refresh token 和过期时间;
  - 选中的打印机序列号、名称和型号。
- 工牌只连这几个地方,没有任何第三方中转服务器:
  - `api.bambulab.cn`(HTTPS):发验证码、登录、拉打印机列表、续期 token;
  - `cn.mqtt.bambulab.com:8883`(MQTT over TLS):订阅打印机状态;
  - `ntp.aliyun.com`:对时,只用来显示时间。
- 串口日志里不会打印 token、序列号、Wi-Fi 密码,只打印「set / -」。
- NVS 没有加密。工牌丢了或者要送人,先做一次恢复出厂设置。

## 登录过期

- 固件每 6 小时检查一次,离过期不到 7 天就在后台自动续期;MQTT 被拒绝时也会先尝试续期。
- 剩 1–3 天时,每天第一次检查会弹一张黄色便签「过几天要重新扫码哦」,按任意键收起。
- 续期失败或已经过期,屏幕显示「要重新扫码啦」。按一下中键,屏幕出现二维码,按上面的步骤连热点,网页里只要重新收一次验证码,Wi-Fi 和打印机都保留。

## 方案 B:局域网模式(不用拓竹账号)

如果验证码登录被拦(比如要过滑块或二次验证),可以让工牌直接连局域网里的打印机:

1. 在打印机屏幕上打开局域网模式(设置 → 网络),记下 **IP** 和 8 位 **访问码**;**序列号 SN** 在 设置 → 设备 里。建议在路由器里给打印机固定 IP。
2. 配网网页第 ① 步照常选 Wi-Fi(必须和打印机在同一个局域网)。跳过第 ②③ 步,展开最下面的「高级 · 用局域网连接」,填 IP、访问码、SN,点「用局域网绑定」。
3. 工牌重启后直连 `mqtts://<IP>:8883`(用户名 `bblp`,密码是访问码)。打印机用的是自签名证书,所以只有这条连接跳过证书校验;拓竹云和 HTTPS 仍然校验证书。

局域网模式只支持一台打印机,离开家里的网络就看不到状态,也没有过期提醒。

## 重新配网

长按中键打开设置,选「重新配网」,屏幕出现二维码,按上面的步骤重新来一遍。重新配网时用的那个 Wi-Fi 会排到已保存列表的第一位;已经存满 5 个的话,会挤掉最久没用的那个。

## 多个 Wi-Fi

工牌最多保存 **5 个** Wi-Fi(比如家里、公司、手机热点),换个地方不用重新配网,有信号就自动连。

**怎么连**:开机和断线后,工牌先扫描周围的 2.4 GHz 网络,只在**已保存**的网络里选——信号最强的先试;每个最多等 15 秒(密码不对或认证失败会立刻换下一个);都连不上就按 1、2、4 … 最长 60 秒的间隔重新扫描再试,和以前的断线重连节奏一样。**不会自动进入配网页**,要改请手动进「重新配网」。只保存了 1 个 Wi-Fi 时,行为和 v4.7 完全一样(不扫描,直接连)。

**怎么管理**(不需要重新登录拓竹账号):

1. 长按中键打开设置,选「重新配网」,屏幕出现二维码。
2. 手机连上 `Passport-XXXX` 热点,打开配网网页。已经配置过的工牌,网页先显示入口页:点「**管理 Wi-Fi**」(「重新登录拓竹账号」用于登录过期或换账号;「换打印机?重新走一遍完整设置」是原来的完整流程)。也可以直接打开 `http://192.168.4.1/?mode=wifi`。
3. 列表里是已保存的 Wi-Fi 名称(**密码不会显示**),当前连着的那个会标出「当前连着」和信号强弱。可以:
   - **添加**:点「+ 添加 Wi-Fi」,选一个当前搜到的 2.4 GHz 网络,填密码(开放网络留空;密码至少 8 位),点「保存并连接试试」。工牌会**先试着连这个网络,最多等 15 秒,连上了才保存**;密码不对或连不上会提示,列表保持原样。试连时手机可能断开几秒,属于正常现象;工牌连上以后会**留在新网络上**(不会马上切回信号最强的那个,下次开机或掉线才重新按信号选)。
   - **已经存了 5 个**:「添加」按钮会变灰,要**先删掉一个再添加**。页面没有「改密码」按钮:路由器改了密码,就先删掉旧的,再添加一次。
   - **删除**:点名称右边的「删除」,确认后立即生效。**最后一个不能删**(按钮置灰;没有 Wi-Fi 工牌就上不了云),要换网请先添加新的再删旧的。删除的是当前连着的那个时,工牌会自动换到其他已保存的 Wi-Fi,页面可能断开几秒。如果页面提示「没收到工牌的回复,可能已经删除。重新连上工牌热点后刷新页面,再点「管理 Wi-Fi」确认」,说明请求发出后手机断开了,没拿到结果:重新连上热点、刷新页面看列表就知道有没有删掉。
4. 点「完成」,工牌重启退出配置模式。添加和删除是立即保存的。**不点「完成」直接关网页不会退出配置模式**(配网热点一直开着,要重启或断电);一次成功的添加/删除/完成之后,升级时出现的「之前保存的 Wi-Fi 已自动加入」横幅就不再显示。

**限制**:

- **不支持隐藏的 Wi-Fi**:它们在扫描里看不到,不会被尝试。
- 添加时会试连并验证密码;但之后路由器改了密码,只会在下次连接时被跳过(日志里是认证失败),需要删掉再添加。
- 只支持 2.4 GHz;需要网页登录的公共 Wi-Fi(酒店、商场)和企业认证 Wi-Fi 连不上。
- 局域网模式必须和打印机在同一个网络,换到别的 Wi-Fi 后看不到打印机。

**安全说明**:配网热点 `Passport-XXXX` 是开放的(没有密码),配网页的接口——新增的 `/api/wifi_*` 和原来的 `/api/bind` 等——**都没有鉴权**,所以配置模式开着的时候,附近连上这个热点的人就能增删 Wi-Fi(和重新绑定)。热点只在配置模式下才开启(没配置过的工牌开机时、设置里选「重新配网」、登录过期要重新扫码时),已配置好的工牌正常开机不开热点,配好后重启即关闭。这一点和 v4.7.x 的风险等级一致,v4.8 没有放大。想降低风险:只在需要时才进「重新配网」,配完点「完成」重启退出。

**配网页接口(v4.8)**

| 接口 | 说明 |
|---|---|
| `GET /api/wifi_list` | `{"configured":true,"max":5,"migrated":false,"items":[{"ssid":"…","connected":true,"rssi":-48},{"ssid":"…","connected":false}]}`。**不扫描**(扫描会打断 STA 链路),**不回密码**。`rssi` 只给当前连着的那个(`esp_wifi_sta_get_ap_info`)。`configured` = 工牌里已有云端或局域网绑定。`migrated` = 刚从 v4.7.x 升上来、还没在页面上增/删/点完成过 |
| `POST /api/wifi_add` `{ssid,password}` | 先试连(最多 15 秒),成功才写 NVS。同名 = 更新密码。`400` 密码格式不对 / `409` 已满且是新网络 / `502` 密码不对或连不上 |
| `POST /api/wifi_del` `{ssid}` | `409` = 只剩最后一个;`404` = 没有这个 Wi-Fi |
| `POST /api/wifi_done` | 重启工牌 |

`502` 的两种文案靠 STA 断开原因码区分:`4WAY_HANDSHAKE_TIMEOUT`(15)、`HANDSHAKE_TIMEOUT`(204)是 ESP-IDF 文档里「密码不对」的原因码,归「密码不对」;其余(没搜到、超时、被拒绝……)归「连不上」。**这个分类只有 ESP-IDF 文档和主机测试支撑,没有在真机上验证过。**

页面分流:`/?mode=reauth` 只显示登录卡片(固件的「重新登录」入口);`/?mode=wifi` 直接进列表;其余看 `wifi_list.configured`:已配置 → 入口页,未配置 → 首次 3 步。页面里所有来自外部的字符串(SSID、打印机名、服务器提示)都用 `textContent` 写入,不拼 HTML。

NVS 占用:列表是 1 个 blob(1 组 6 项,5 组 18 项)+ 升级标记 `wmig` 1 项 = 最多 **19 项**;旧键 `ssid`/`pass` 是 v4.7.x 就有的,不算新增。24 KB 的 NVS 共 756 项。

**升级与降级**:从 v4.7.x 升上来(包括「只更新应用」,保留配网),原来的那个 Wi-Fi 会自动成为第 1 个,不用重新配。保存列表时,第 1 个 Wi-Fi 同时写回原来的 `ssid` / `pass`,所以降级回 v4.7.x 还能连第 1 个;在旧固件里重新配过网再升上来,新配的那个会排到最前面。
