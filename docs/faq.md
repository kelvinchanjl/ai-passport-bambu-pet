# 常见问题

## 屏幕一直是「连接中…」或「未连上拓竹云」

刚开机或刚切换打印机时,先显示「连接中…」;30 秒内还没收到打印机数据,就显示「未连上拓竹云」。排查顺序:

1. **Wi-Fi**:必须是 2.4 GHz。改过路由器密码或名称的话,长按中键 → 设置 → 「重新配网」。
2. **账号区域**:固件只连拓竹**中国区**云(`api.bambulab.cn` / `cn.mqtt.bambulab.com`),国际区账号连不上(见 [已知限制](limitations.md))。
3. **打印机本身**:在 Bambu Handy 里看打印机是否在线。打印机开了「仅局域网模式」时,云端收不到它的数据,请用 [局域网模式](setup.md#方案-b局域网模式不用拓竹账号)。
4. **网络在恢复中**:断网后 Wi-Fi 按 1 秒到 60 秒逐步加长间隔重连,MQTT 每 10 秒重连一次,恢复后会自己回来,不用重启。

## 显示「读不到打印机数据」

已经连上拓竹云,但打印机发来的报文解析不了。一般是打印机固件更新后报文格式变了。请带上打印机型号和固件版本提 issue。

## 显示「要重新扫码啦」/ 登录过期

拓竹 token 过期了,后台续期也失败了。按一下中键,用手机重新扫码,网页里只要重新收一次验证码,Wi-Fi 和打印机都保留。详见 [首次配网](setup.md#登录过期)。

## 收不到验证码 / 登录被拦

- 确认第 ① 步的 Wi-Fi 能上网:发验证码之前工牌要先连上你家的 Wi-Fi。
- 如果拓竹要求滑块验证或二次验证,工牌做不了,请改用 [局域网模式](setup.md#方案-b局域网模式不用拓竹账号)。

## 恢复出厂设置

1. 长按中键(约 0.5 秒)打开设置。
2. 用上/下键选到最下面红字的「恢复出厂设置」,单击中键进入确认页。
3. **松开中键后再按住中键 5 秒**,屏幕有倒计时和进度条,走完工牌清除配置并重启。
4. 不到 5 秒松手,或者按上/下键,都会取消并回到设置页。

恢复出厂只清除 `petcfg`(Wi-Fi、拓竹登录、打印机列表),固件本身不受影响,重启后进入配网页。

## 想先看看效果 / 拍视频

长按中键 → 设置 → 「演示模式:关」单击中键切成「开」。演示模式下单击中键依次切换 6 种状态(右上角显示 1/6…6/6),上/下键照样切详情页和耗材页。没配网的工牌在配网页背后也是演示数据。

## 电量显示 `--%`

读不到电量计时显示 `--%`,电池图标变灰。电量每 30 秒读一次并做了平滑,刚开机可能要等一会儿。

## 时间显示 `--:--`

还没联网对时。连上 Wi-Fi 后会通过 NTP 自动对时(北京时间)。

## 打印机名字显示不全

名字太长会用省略号截断。中文名里如果有字库里没有的生僻字,会显示成型号。

## 刷机后配网没了

用完整镜像(`0x0`)刷写会清掉配网信息,这是正常的。以后升级请用「只更新应用」,见 [刷机步骤](flashing.md#如何保留配网)。
