# 已知限制与规划

## 已知限制

- **没有充电图标**:工牌硬件读不到"是否在充电",所以电量只显示百分比,不显示充电状态。
- **只支持拓竹中国区账号**:HTTPS 接口固定是 `api.bambulab.cn`,MQTT 默认 `cn.mqtt.bambulab.com`。国际区账号目前用不了。
- **拓竹云接口不是官方公开 API**:接口路径和报文格式来自社区逆向,拓竹改了接口固件就可能失效。
- **验证码登录可能被风控拦截**:遇到滑块或二次验证时只能改用局域网模式。
- **局域网模式只支持一台打印机**,而且必须和工牌在同一个网络。
- **最多 4 台打印机**(云端模式)。
- **只支持 2.4 GHz Wi-Fi**。
- **NVS 没有加密**:Wi-Fi 密码和拓竹 token 以明文存在工牌 Flash 里,能物理接触工牌的人可以读出来。转手前请恢复出厂。
- **常亮屏幕,没有休眠**:固件不进入深睡眠,续航取决于电池容量。
- **机型覆盖**:H2C(带 AMS HT 和 AMS 2 Pro)实机测过;H2D 用公开报文回放测过;X1 / P1 / A1 系列按报文格式兼容,没有实机验证。
- **只更新应用要求分区表相同**:从别的固件切过来必须用完整镜像。

## 规划中(还没做)

- **打印封面图**:在首页显示正在打印的模型缩略图。拓竹云的任务列表里有封面链接,难点是在没有 PSRAM 的芯片上解码图片(PNG 解码需要 45–50 KB 额外内存),还在评估。
- **多台打印机的首页信息牌**:显示当前时间、主人的名字 / 头像 / 一句话简介、工牌电量和打印机列表。
- **断网时的轻提示**:断网时先显示一个小的「重连中」标记,较长时间连不上才切到整页提示。
- **断网后引导重新配网**。
